## Sobre o projeto

Projeto educacional para aprofundar conhecimentos sobre **Props em React**.

Demonstra como passar dados entre componentes pai e filho, validação de props e padrões de uso eficiente de props para criar componentes reutilizáveis.

---

## Conceitos cobertos

- ✅ Passagem de props
- ✅ Props em componentes filho
- ✅ Default props
- ✅ Props obrigatórias
- ✅ Componentes reutilizáveis
